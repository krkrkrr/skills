# frontend-review

Audit an existing frontend repo — triage, CI, hygiene, dependencies, testing, security, state management, and rendering performance — with a KPI baseline that only ratchets tighter. Committed review markdown is written as [OKF](https://okf.md/spec/) concepts.

Part of the [skills](https://github.com/krkrkrr/skills) library — see the repository's [README](../../README.md) for installation.

## Source

Derived from the `frontend-review-*` and perspective skills in [mizchi/skills](https://github.com/mizchi/skills/tree/a3f2f1bac20fc500c2688ffe6ca4ce048d0cfedc) (`a3f2f1b`) by mizchi, licensed under the MIT License. Modified: fourteen skills condensed into one, the unpublished audit scripts replaced with inline commands, committed markdown written as OKF concepts, and evals added.
