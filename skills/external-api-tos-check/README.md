# external-api-tos-check

Confirms a third-party API/SDK/service's Terms of Service or Developer Policy allows the planned behavior before implementation, and records material constraints as an ADR, listing the checked terms documents (URL, last-updated date, read date) as [OKF](https://okf.md/spec/) `sources`.

Part of the [skills](https://github.com/krkrkrr/skills) library — see the repository's [README](../../README.md) for installation.
