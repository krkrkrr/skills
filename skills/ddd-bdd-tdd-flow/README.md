# ddd-bdd-tdd-flow

Feature/application flow across bounded contexts — orient (Phase 0) → DDD SUDO modeling → BDD Gherkin features → property-based tests → t_wada TDD implementation. The `doc/` tree is written as an [OKF](https://okf.md/spec/) bundle, one `type` per document role.

Part of the [skills](https://github.com/krkrkrr/skills) library — see the repository's [README](../../README.md) for installation.
