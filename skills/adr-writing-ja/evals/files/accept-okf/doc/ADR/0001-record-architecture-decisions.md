# ADR-0001: アーキテクチャ上の決定を ADR として記録する

- 日付: 2025-04-01

## ステータス

Accepted

## 背景

設計判断の理由がチャットや口頭に散らばり、後から参加したメンバーが経緯をたどれない。

## 決定

アーキテクチャ上重要な決定は、Nygard 形式の ADR として `doc/ADR/` に記録する。

## 影響

決定の理由を後から参照できる。ADR を書く手間が増える。
