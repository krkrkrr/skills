# extract-glossary

Extract domain-specific terminology, tech stacks, and onboarding Mermaid diagrams from a repo or GitHub org, as an [OKF](https://okf.md/spec/) knowledge bundle — one concept per term, repository, and architecture topic.

Part of the [skills](https://github.com/krkrkrr/skills) library — see the repository's [README](../../README.md) for installation.

## Source

Adapted from [mizchi/skills](https://github.com/mizchi/skills). Modified: the output is an OKF bundle instead of single glossary / map / architecture files, with a bundled `scripts/okf-index.sh` index generator.
