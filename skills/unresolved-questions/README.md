# unresolved-questions

Files unknowns, provisional decisions, and deliberately-skipped work as one file per question under `doc/questions/<status>/`, where the directory *is* the status. Each question is an [OKF](https://okf.md/spec/) concept (`type: Question`), indexed by `doc/questions/index.md`.

Part of the [skills](https://github.com/krkrkrr/skills) library — see the repository's [README](../../README.md) for installation.
